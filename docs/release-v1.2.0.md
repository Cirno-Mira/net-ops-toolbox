# NetOps Toolbox v1.2.0

面向 Windows 的网络运维与安全测试工具箱，基于 PyQt5 构建。本次版本新增被动发现、
SNMP 设备信息、变更监控、流量画像与 SYN Flood 五个模块，并重写了项目文档。

## 新增功能

### 被动发现

- 旁路监听 ARP、DHCP、mDNS、NBNS、LLDP、CDP，不发送任何探测报文。
- 自动维护 IP / MAC 资产表、DHCP 客户端表与交换机邻居拓扑。
- 内置审计规则：IP 冲突、MAC 漂移、ARP 扫描、流氓 DHCP、网关 MAC 被替换。
- 支持生成中文审计结论、导出资产 CSV，并将选中主机送入端口扫描。

### SNMP 设备信息

- 自实现 BER 编解码，不依赖 pysnmp，提供 SNMP v1 / v2c 客户端。
- 支持系统信息、接口表、ARP 表、IP 地址表与 LLDP 邻居读取。
- 支持 GET、GETNEXT、GETBULK 及任意 OID 查询。
- 提供常见团体名只读探测与配置风险报告。
- sysName / sysLocation 写入默认隐藏，需显式授权并二次确认。

### 变更监控

- 支持 ARP 扫描、Ping 扫描、SNMP 与被动发现四种数据源。
- 周期性采样并写入 SQLite 快照库。
- 与基线或上一份快照进行字段级对比，输出新增、消失与属性变化。
- 历史快照支持浏览、设为基线、导出 JSON 与删除。

### 流量画像

- 按五元组聚合流表，输出 Top Talkers、Top 会话与 Top 目标。
- 结合端口与载荷识别应用，支持 TLS SNI 与 HTTP Host。
- 仅保留统计数据，不保存原始报文。
- 支持实时抓包与 pcap 离线分析，流表可导出 CSV。

### SYN Flood

- 支持速率、时长、包数上限与批量大小配置。
- 提供目标端口探测、目标 MAC 解析与演练模式。
- 默认拒绝公网目标，启动前需显式确认测试授权。
- 单发送线程、批量发包，停止后不残留后台线程。

## 改进

- README 全文重写，统一术语、安装步骤与功能说明。
- 文档与界面截图中的内网地址统一替换为 RFC 5737 文档地址，MAC、路径与网卡名称已脱敏。
- 自检扩展至核心层与界面层共 20 节，新增模块均纳入自检范围。
- 打包脚本补充 LLDP / CDP 相关 hidden imports。

## 安装

1. 下载本页附件 `NetOpsToolbox.exe`。
2. 双击运行，按提示允许管理员权限（UAC）。
3. 抓包、ARP 牵引与透明代理功能需要安装 [Npcap](https://npcap.com/)；
   仅使用扫描、SNMP、子网计算等功能时可不安装。

支持 Windows 10 / 11（64 位），单文件免安装。

## 权限说明

| 功能 | 所需权限 |
| --- | --- |
| 资产发现（Ping 模式）、端口扫描、运维工具 | 普通用户 |
| SNMP 查询、变更监控（被动 / SNMP 模式）、pcap 离线分析、SYN Flood 演练模式 | 普通用户 |
| ARP 扫描、被动发现、实时流量画像、抓包、透明代理 | 管理员 + Npcap |
| SYN Flood 实际发送、ARP 牵引 / 断网 | 管理员 + Npcap + 目标授权 |

## 注意事项

本工具仅可用于本人拥有或已获得书面授权的网络与设备。压力测试、SYN Flood、
DHCP 测试等功能会实际占用目标资源，请提前确认影响范围，并在业务低峰期使用。

完整功能说明、使用流程与常见问题请参阅
